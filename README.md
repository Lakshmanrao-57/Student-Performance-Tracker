# Student Performance Tracker

A simple and interactive web application designed to help students organize study tasks, monitor learning progress, and build consistent study habits.

## Overview

The **Student Performance Tracker** brings study planning and productivity tools together in one dashboard. Students can organize their learning activities, track completed tasks, view their weekly schedule, and use a Pomodoro timer to support focused study sessions.

## Features

- **Study Dashboard** — View study statistics and progress at a glance.
- **Study Task Management** — Organize topics and learning activities.
- **Progress Tracking** — Monitor completed study tasks and daily goals.
- **Weekly Calendar** — View and organize your weekly study schedule.
- **Daily Check-in** — Encourage consistent study habits.
- **Pomodoro Timer** — Use focused study sessions with breaks.
- **Responsive Interface** — Access the dashboard across supported screen sizes.
